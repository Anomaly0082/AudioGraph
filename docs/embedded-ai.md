# 简版内置 AI Graph 助手（P8）

无需配置外部 MCP 客户端。桌面直接请求你指定的模型服务，C++ 的 Node、Graph、Executor 和控制协议保持不变。它目前是一次性 Graph 提案助手，不是自主循环 Agent 或 Workflow 引擎。

## 使用

1. 启动桌面程序，连接一个现存工作目录；如有旧任务，先释放记录。
2. 在「AI Graph 助手」填写兼容地址（例如 `https://api.openai.com/v1`）、模型名称和 API Key。地址是基础路径，不要带 `/chat/completions`。模型必须支持 Chat Completions 的 `tools` / `tool_calls`。
3. 把输入文件放在工作目录，描述完整需求，例如「读取 input.wav，降低 6 dB 后写入 output.wav」。当前文件音频仅支持 PCM16 WAV，不会自动增加降噪、变声或 ASR 能力。
4. 点击「生成 Graph 提案」。程序发现当前节点、请求模型，然后调用 C++ 校验。此时不执行节点、不创建输出文件。
5. 检查提案的输入/输出路径与 Graph JSON，选择「确认并执行」或「拒绝提案」。确认才交给原有任务入口执行，实际状态、错误和输出位于任务区。
6. 完成后可查看 AI 结果解释；解释失败不会改变真实结果。释放任务记录后可继续下一轮。若需保留 Graph，用原有保存功能另存。

所有相对路径以连接的工作目录为基准。输出拒绝覆盖已有文件；换一个新文件名再试。若模型只返回澄清文字，补全需求后重新生成；本版不维护多轮聊天历史。

## 请求与执行边界

- 每轮最多一次提案请求、一次独立结果解释请求，不自动重试；请求数上限不等于供应商费用上限。
- 只接受一个名为 `propose_audio_graph` 的函数提案，且仅限当前目录中的 offline/streaming 节点。普通回复只显示，不提取 Markdown/代码块来执行。
- 模型不能调用 Shell、Python、设备、任意工具或更改 API 配置。实时图仍可通过原有手工控制台操作，不对 AI 开放。
- C++ 校验无执行副作用；确认后启动时再次校验。文件边界由现有 workspace 策略负责，不是操作系统沙箱。失败/取消可能留下部分新文件，不提供事务回滚。
- HTTP 总等待上限 45 秒；请求 128 KiB、响应 1 MiB、提案 64 KiB、需求 16 KiB。AI 音频任务等待 10 分钟后请求协作取消，不保证瞬时终止。
- 「停止 AI 请求」按本轮 requestId 取消；「停止执行」针对实际 taskId。取消完成的音频任务不再请求 AI 解释。窗口关闭也会取消 AI 请求并结束自己的后台会话。
- 会话变化使旧提案/回复失效。任务状态未知时停止 AI 后续操作，不冒充成功，不自动重新启动。

## 数据与 Key

需求文字、离线节点描述、提案（包含文件路径和参数）、任务结果摘要会发送到所填模型服务。**不上传音频文件本体**，也不读取工作目录文件列表给模型；请勿在需求中放不希望外发的内容。结果可能包含文本节点的文本或文件绝对路径。

Key 仅存当前进程/界面内存，不写入配置、localStorage 或日志；HTTP 使用 Authorization 头。关闭程序需重新填写。改变地址会清空 Key，避免误发到新服务。这不代表内存已作密码学安全擦除。

远端仅允许 HTTPS，本机回环允许 HTTP；不接受地址中的用户名、密码、查询参数或 fragment，不跟随重定向。回环 HTTP 不走环境代理；HTTPS 保持正常证书校验，可使用系统环境代理。错误不会回显供应商错误正文、Key 或认证头。

## 代码与验证

- React：`AiPanel.tsx` 管理提案/审批/解释，`ai-model.ts` 管理纯数据校验与审批防重复提交；App 仍拥有真实任务状态。
- Rust：`ai.rs` 管理兼容 HTTP、严格解析、取消和边界；`ai_commands.rs` 先查询节点、后校验提案，不启动任务。
- 测试：`npm test`、`npm run build`；缓存依赖后在 `src-tauri` 执行 `cargo test --offline`。本地 HTTP 模拟不需要真实 Key 或费用。

工具调用格式按 [OpenAI 官方说明](https://developers.openai.com/api/docs/guides/function-calling) 实现。兼容供应商对 JSON Schema/工具调用的支持可能不同，不能保证任意「兼容接口」都支持。自动测试使用本地模拟服务；真实供应商连通性、计费和模型提案质量需填入自己的配置后验证。
