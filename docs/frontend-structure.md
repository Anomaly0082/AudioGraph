# 前端结构与手动验收

页面与画布重构不改变C++ Node/Executor或MCP协议。后续新增的参数对比实验扩展了Rust桌面命令与AI候选提案入口，仍复用原有C++执行契约，详情见[参数实验](parameter-experiments.md)。

## 页面与操作

2026-10-02修正：Graph提交按钮复用会话的taskBlocked判断，不再因保留上一条TaskView而禁用。成功/失败/取消任务完成收尾后可再次提交；运行中、状态未知或尚未释放仍阻止提交，历史记录继续保留。SSR回归覆盖这些状态、旧会话隔离和未校验/全局忙碌限制。输出文件已存在仍按原策略拒绝覆盖，修改文件名后需重新校验。

最新界面整理：移除“单次Graph提案”旧入口，工作台的AI功能使用统一工具助手。旧useAiWorkflow不再挂载，模板输入由App独立保存。原生details/summary统一替换为Disclosure的“查看/收起”按钮；收起不卸载编辑内容，JSON错误仍自动展开。底层工具、任务接口和用户文件未改动。

调用记录默认收在每轮回复的“查看调用详情”中，避免输入、每次工具调用、模型输出和状态按钮占满对话。外层保留回复、简短统计、失败提示和可用的Graph载入操作；详情数据不删除。

AI主要回复支持Markdown排版（标题、列表、强调、代码块和表格）；用户消息、工具参数、原始模型输出和状态详情不做Markdown转换。使用react-markdown与remark-gfm，不启用原始HTML；图片仅显示替代文字，避免渲染时自动请求远程资源。只将HTTP(S)链接呈现为可点击链接。

- **处理工作台**：打开工作区、选择WAV、只读检查格式；使用AI提出需求或从快捷模板准备Graph。模板只准备草稿，不自动执行。
- **编辑器**：Graph页签保留节点画布、参数/导出侧栏、节点目录、JSON高级编辑、运行模式与设备绑定；Workflow页签提供JSON草稿、工作区相对路径打开/另存、校验、运行与停止。两类草稿互不替换，AI载入不自动执行；结果共用运行记录。
- **运行记录**：持久化的手动/AI Graph与Workflow历史、父子关联、配置快照、结果与文件指纹检查；当前手动任务在对应行停止，终态自动收尾，没有独立控制/释放面板。详见[运行记录](run-records.md)。
- **设置**：API地址/模型/Key的保存与恢复，以及设备权限。Key只在该页的密码输入框中显示，不放在工作台。
- 旧版参数实验已退出正式界面，App不再挂载其实验控制器。历史接口/测试暂留，原专用表单不再提供入口。

右上角统一管理工作区；导航始终可用。全局活动条让用户在其他页面也能回到正在处理的任务或待确认AI方案。文件模式默认不访问设备，设备权限在连接时固定，有声执行仍需确认。

## 三种对象不能混为一谈

1. 手工草稿归`useGraphDraft`管理；可以在任务运行时继续编辑，旧校验结果只对原会话和原内容有效。
2. AI提案归`useAiWorkflow`管理；确认执行提交它自己的快照，不覆盖手工草稿。
3. 已提交任务归`useAudioSession`管理；Graph/options在提交前深拷贝冻结，轮询只更新状态/结果，不回读编辑器内容。

用户点击AI方案的「载入编辑器」并确认后，才替换手工草稿并关闭该待确认方案；之后走手工校验/提交。这避免AI仍停在等待确认状态而锁住刚载入的草稿。

切页只更换展示组件，控制器hooks在App顶层保持挂载；不会因为离开工作台就断开后端或重启任务。退出应用仍沿用已有关闭/取消策略。API配置、AI会话和运行记录持久化；Graph编辑草稿及未发送输入不保证跨重启恢复，历史记录不自动恢复执行。AI界面通过会话选择/新建/更早消息访问历史，消息状态优先展示持久轮次是否中断，关联run_id可跳到运行记录。

## 文件职责与阅读顺序

- `src/App.tsx`：应用组装、页面切换、用户确认与跨模块协调，不直接发送Tauri请求。
- `src/pages/`：处理工作台、编辑器、文件、运行记录、设置的展示组件；只接收状态与操作回调。
- `src/hooks/useWorkspaceBrowser.ts`：只读文件浏览、预览请求及迟到响应保护；`workspace-browser-model.ts` 负责文件类型分派、完整配置识别和音频缓存生命周期，`WorkspaceBrowserPage.tsx` 负责目录与预览展示，不绑定实验流程。
- `src/components/`：导航、工作区、输入信息、Graph概览、节点目录和AI展示组件。
- `src/components/GraphCanvas.tsx`：节点位置、端口连线与缩放；不执行音频任务。
- `src/components/NodeInspector.tsx`：按后端描述生成参数表单、设备选择和导出控件。
- `src/graph-editor-model.ts`：不可变Graph增删改、连线约束；不丢弃无关字段。
- `src/graph-canvas-layout.ts`：按实际连接自动排布、端口位置所需信息；无执行调度职责。
- `src/hooks/useAudioSession.ts`：唯一连接与任务状态所有者，包含轮询、断连、错误及迟到响应防护。
- `src/hooks/useGraphDraft.ts`：草稿、选项、校验标记与显式载入/另存；单独保存画布状态，布局变动不使执行校验失效。
- `src/hooks/useAiSettings.ts`：本机设置恢复/保存/清除；不依赖设置页持续挂载。
- `src/hooks/useAiWorkflow.ts`：生成、确认、修正、取消和解释；保留任务归属与请求ID防护。
- `src/hooks/useAudioInput.ts`：只读输入检查，防止旧路径/旧会话的结果覆盖新输入。
- `src/hooks/useExperiments.ts`：实验/模型请求状态和持久化适配，使用同一个音频会话。`experiment-runner.ts`负责可独立测试的串行批次顺序，`experiment-model.ts`负责记录、边界和候选Graph转换。
- `src/api/desktop.ts`：唯一Tauri调用/事件/对话框入口，不把invoke散落在页面。
- `src/types/desktop.ts`：桌面通信与任务快照类型。
- `src/model.ts`、`ai-model.ts`、`workflow-model.ts`、`presentation.ts`：无React依赖的解析、约束、差异、快照和展示转换函数。
- `src/styles/`：基础样式、整体布局、组件样式；`styles.css`只统一导入。

建议从`App.tsx → pages/WorkbenchPage.tsx → useGraphDraft.ts/useAudioSession.ts → api/desktop.ts`阅读。AI部分另看`useAiSettings → useAiWorkflow → AiWorkflowPanel`。本轮没有引入新的路由/全局状态框架，复杂异步保护没有因拆文件而删掉。

这里的`useAiWorkflow`只是前端AI交互流程控制器，不是之前讨论的后端Workflow编排层；它不提供条件、循环、参数搜索或训练接口。

## 用户手动验收

关闭旧窗口，启动新的桌面调试EXE：

```text
apps/desktop/src-tauri/target/debug/audioprocess-prototype.exe
```

1. 确认默认工作台只有输入与方案流程，API配置在设置页；既有配置仍能恢复。
2. 右上角打开音频目录，选择PCM16 WAV，点击「检查音频」，检查采样率/声道/时长。
3. 选择「快捷模板」，填写新的输出名，点击「准备Graph并查看」。应进入编辑器，尚未产生输出；校验后再提交，自动进入结果页。
4. 提交一份较长音频后切换设置/编辑器/工作台；任务应继续。修改草稿后，结果页“提交时的方案”不应改变。
5. 输入一段AI需求后切页再回来，内容不丢；生成方案期间也能切页。确认AI方案应只执行提案，不替换手工草稿。
6. 点击AI方案「载入编辑器」并确认，应替换草稿、关闭待确认方案，且仍需手工校验/提交。拒绝确认不能改草稿。
7. 测试失败修正、取消及重连；不得自动重跑，不得覆盖已有文件。失败记录释放不会删除产物。

本轮未使用Computer Use或真实模型API。自动验证包含纯函数与服务端渲染（SSR）测试，但SSR不能证明实际窗口布局、文件对话框或异步页面交互正确；这些由以上手动步骤补齐。

## 节点编辑器验收

1. 载入音量调整模板，画布应显示真实端口与两条连线。移动节点、缩放和整理布局后，JSON与校验标记不应改变；切页回来位置应保留。
2. 选中gain，修改gain_db并应用，JSON随之变化，原校验失效。留空、超范围或非数值不得写成0/NaN；改回合法值后可继续应用。
3. 在画布点击连线并按Delete（或工具栏删除）移除，分别用拖拽和两次点击端口重新连接。输入端口已有连线时，新连线验证通过才替换；重复连接为无操作。类型不符、跨执行域和环路应被拒绝，原Graph不变。
4. 添加节点时ID不冲突；删除节点需确认并移除其连接/导出。删完所有节点后仍可从目录添加；空草稿不能校验、保存到后端或执行。
5. 展开JSON修改参数/连接，画布应更新；坏JSON显示错误、保留原文，不显示可编辑的旧画布。修正后恢复；未知节点/字段不应静默丢弃。
6. 在节点侧栏增加/删除结果导出；保存JSON后重新载入，节点、参数、连线和导出一致。布局不写入执行JSON，重新载入时自动排布。
7. 实时模板中单独选中输入、输出节点，刷新设备后选择并应用。未授权时不能刷新；默认静音，不能因为画布操作自动启动设备。
8. AI提案载入后可同样编辑；已提交任务继续使用原快照，不受后续画布编辑影响。

表单输入点「应用」才写入草稿；尚未应用的临时输入不跨检查器/页面保留。首版不提供撤销历史、子图、分组、复制粘贴或Workflow。原有输出不覆盖、实时有声确认和任务归属限制不变。

画布交互补充：按住鼠标中键可在空白、节点或端口上开始自由平移；不移动节点坐标、不改变Graph或校验结果，跨页面保留视角。连线用按端口类型着色的平滑曲线，不再显示编辑器下方的文本连接列表。拖动已有输入端口可把原线改接至其他输入；空输入也可反向拖到输出。拖到空白、按Esc或右键取消时恢复原线；悬停目标显示可连接/无效状态。缩放按钮围绕视口中心缩放，百分比按钮重置视图；整理布局同时重置视角。请特别验证平移与缩放之后端口连线仍准确、中键不触发浏览器自动滚动、选中线后Delete不影响节点参数输入。
