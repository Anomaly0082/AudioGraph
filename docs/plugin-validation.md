# 外部独立插件验收记录

## 2026-10-02：峰值归一化插件

目的：验证外部开发者仅使用导出的开发套件，能否独立实现真实节点并接入 AudioGraph，不依赖主程序内部计算模块，也不修改宿主接口。

交付插件为 `org.devkit.normalizer` 0.1.0，节点类型 `org.devkit.normalizer.peak_normalize_v1`。使用 C ABI 0.1、包格式 v2、离线整段同步执行；输入 Audio，输出 Audio 和 Number 实际增益。算法位于自带辅助 DLL，静音阈值来自随包资源，配套 Graph 为 WAV 输入→归一化→WAV 输出并导出增益。

### 证据与范围

- 外部开发者交付了独立源码、完整插件包、配套 Graph、测试日志和验证报告。源码构建只引用公开 SDK；没有为接入它修改 AudioGraph 生产接口。
- 外部报告及日志记录原样 SDK 示例通过、新插件 30/30 项独立测试通过。它们是开发者自己的模拟宿主和包测试，不是本仓库重新执行的自动化结果，也不等价于全部实际宿主场景通过。
- 本项目复核了插件源码、公开 ABI 使用和报告，并安排独立只读代码审查，未发现阻止接入验证的问题；另外核对了交付包入口 DLL、辅助 DLL、nodes.json 和资源这四个声明成员的 SHA256，均与 manifest 一致。
- 用户随后确认“验证了，没问题”，作为实际主程序手动接入验收通过的反馈记录。未取得逐项操作日志或输出测量记录，因此不据此声称取消、异常、卸载、长期并发等全部边界已在实际程序复测。

结论：这次实验支持“外部开发者仅凭套件即可开发并接入独立节点”的当前设计方向；未发现需要为该插件改变 Node、Graph、Executor 或 C ABI 的证据。结论仅适用于本次插件与当前版本，不构成任意原生插件安全、所有算法适配或稳定 ABI 承诺。外部插件源码和二进制没有因此并入本仓库或开发套件。

### 文档反馈与收尾

1. **Number 导出说明不足**：在[节点开发约定](plugin-development.md)补充端口声明、Graph exports 字段片段、Number 的 type/value 结果格式，并区分数值导出与生成文件。
2. **可选参数默认值的投递方式不明确**：补充显式值、默认值、缺失可选参数和缺失必需参数的处理规则，以及 create 接收标准化具名参数表的说明。

协作取消、实验 ABI 和同步执行限制已在规范中明确，不因本次验收改成硬实时取消或新增异步能力。此次修订只补文档并重新导出套件，接口和实现不变。
